## 🎯 Objectives

- Understand the fundamental concepts of Machine Learning and its role in Artificial Intelligence.
- Explain how machines learn from data through computational models.
- Differentiate the main types of machine learning based on the learning paradigm.
- Identify the characteristics and applications of supervised learning.
- Understand the basic principles behind Decision Trees for classification and prediction tasks.


## 📌 Topics

- 🤖 What is Machine Learning?
- 🧠 How Do Machines Learn?
- 📊 Types of Machine Learning
  - Supervised Learning
  - Unsupervised Learning
  - Reinforcement Learning
- 🎯 Supervised Learning
- 🌳 Decision Trees
- 📈 Logistic Regression



## 🧠 Activities

- 💬 Discuss real-world examples of Machine Learning applications.
- 📺 Watch a short introductory video on how machines learn from data.
- 🐍 Explore a simple supervised learning example in Python using Scikit-learn.
- 🌳 Visualize and interpret a Decision Tree classifier.
- 📈 Train and understand logistic regression. 
- 📝 Solve a short quiz to reinforce key concepts covered during the session.
