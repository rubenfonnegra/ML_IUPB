# 🤖 Semana 6: Unsupervised Learning and $k$-Means Clustering

<span class="badge badge-blue">🎲 Unsupervised Learning</span>
<span class="badge badge-green">🎯 K-Means</span>


## 🎯 Objectives

- Understand the differences between supervised and unsupervised learning.
- Explain the main goals of unsupervised learning algorithms.
- Identify common real-world applications of clustering techniques.
- Understand how the $k$-Means algorithm partitions data into clusters.
- Learn how to select an appropriate number of clusters.
- Implement and visualize $k$-Means clustering using Scikit-learn.

## 📌 Topics

- 🎲 Introduction to Unsupervised Learning
  - Learning without labeled data
  - Discovering hidden patterns
  - Clustering
  - Dimensionality reduction
  - Anomaly detection

- 🌍 Applications of Unsupervised Learning
  - Customer segmentation
  - Recommendation systems
  - Image segmentation
  - Document clustering
  - Fraud detection
  - Biological data analysis
  - Market basket analysis

- 🎯 $k$-Means Clustering
  - Cluster centroids
  - Distance-based clustering
  - Assignment and update steps
  - Iterative optimization
  - Advantages and limitations

- 📊 Choosing the Number of Clusters
  - Elbow Method
  - Silhouette Score
  - Practical considerations


## 🧠 Activities

- 💬 Discuss the differences between supervised and unsupervised learning.
- 📺 Watch a visualization of how $k$-Means builds clusters step by step.
- 🐍 Implement the $k$-Means algorithm using Scikit-learn.
- 🎨 Visualize clusters and centroids on two-dimensional datasets.
- 📈 Apply the Elbow Method to determine the optimal number of clusters.
- 🔍 Compare clustering results using different values of **$k$**.
- 📝 Complete a short quiz about clustering concepts and applications.
